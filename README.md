# enduring-door

Find My Reader quiz for *Enduring* by Kami Yonce.

## Live URL (after Pages is on)

https://kamiyonce.github.io/enduring-door/door.html

## Turn Pages on (once)

1. Open this repo on GitHub.
2. **Add file → Upload files** and drop `door.html` plus the `assets` folder from `enduring-pages.zip`.
3. **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/** (root)
   - Save.
4. Wait one minute. Open the URL above.

Cloudflare Pages can use this same repo later: Workers & Pages → Create → Connect Git → `kamiyonce/enduring-door`.
